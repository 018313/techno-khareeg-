# تكنو خريج - Techno Khareeg

> منصة تواصل لخريجي قسم تكنولوجيا التعليم - تربط 27 خريج بفرص عمل حقيقية.

تكنو خريج هي أول منصة متخصصة لخريجي تكنولوجيا التعليم في مصر، هدفها سد الفجوة بين الدراسة وسوق العمل.

### ✨ المميزات الرئيسية
- **ملفات شخصية للخريجين:** كل خريج له بروفايل بمهاراته وأعماله.
- **لوحة وظائف حقيقية:** فرص عمل من شركات ومدارس تطلب تخصصنا بالاسم.
- **معرض أعمال الطلاب الجامعية:** عرض لمشاريع التخرج بشكل احترافي.
- **شبكة تواصل مغلقة:** تواصل مباشر بين الخريجين وبعض.

### 🛠️ التقنيات المستخدمة
- **Next.js 14 (App Router)** - للسرعة والـ SEO
- **Tailwind CSS** - للتصميم
- **Prisma / Supabase** - لقاعدة البيانات
- جاهز للـ Deploy على سيرفرات TIEC
